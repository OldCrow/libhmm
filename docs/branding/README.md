# Branding assets

Social-media and internal branding imagery for libhmm, part of the
OldCrow "corvid cartography" family (see corvus `docs/branding/`). The
SVGs are the canonical sources; all text is outlined as paths, so they
render identically without any installed fonts. PNGs are exports of the
SVGs. Masters carry no version number — stamp one ad hoc for a release
if wanted.

| File | Size | Use |
|---|---|---|
| `libhmm-github-social.{svg,png}` (+`@2x`) | 1280×640 (2:1) | GitHub repository social preview |
| `libhmm-linkedin.{svg,png}` (+`@2x`) | 1200×627 | LinkedIn link/post card |
| `raven-mark.{svg,png}` | 800×400 | Standalone raven mark |

Design concept and rules are in
[philosophy-corvid-cartography.md](philosophy-corvid-cartography.md).

Palette: ink `#161b23`, bird `#06080b`, cream `#e7e0cf`, gold `#c8a24e`.
